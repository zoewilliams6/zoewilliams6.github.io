TEST YOUR USELESS TRIVIA KNOWLEDGE

The extension that I selected was a free API that I found through API Ninjas that generates random trivia. There were category options but I would've had to pay for a premium account, so all the trivia falls under a general umbrella (no particular genre). I also added a loading bar that appears once the “show answer” button is pressed. I was going to add a random image generator API, but I found that it really wouldn’t have made any sense to have random images appear that had no correlation to the trivia questions themselves.

My original thought for implementing an API in my project was to use Spotify’s API, which I still plan to do, but I think my original idea from last week was a bit too ambitious. I might do something along the lines of albums, artists, and album covers but we’ll see once I get there. I am interested in using Spotify’s API, and I think it has a lot of useful information, but my concern is the learning curve/implementation process that will come along with it.
